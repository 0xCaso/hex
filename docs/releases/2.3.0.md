## Hex 2.3.0

- Adds Windows (beta) for x64 and ARM64. Hold Ctrl+Space to dictate into any
  app. Hex lives in the system tray, starts at sign-in, and updates itself from
  signed releases. On x64 it uses the GPU through Vulkan; ARM64 runs on the CPU.
- Streams every dictation on macOS, Linux, and Windows: Hex transcribes while
  you speak, so releasing the shortcut finishes in about a tenth of a second,
  however long you talked. A 2-minute dictation finishes in 0.1 s instead of
  0.9 s on an RTX 5070 Ti and 2.8 s on a MacBook Air M4. If streaming fails,
  Hex transcribes the whole recording as before, so nothing is lost.
- Switches English dictation to Parakeet Unified English, the streaming model,
  once. Your previous model stays downloaded and one click away in Settings ›
  Local transcription. Other languages keep their model.
- Removes Transcribe during pauses: streaming replaces it.
- Adds Shortcut mode (Settings › Dictation): Hold to dictate while the shortcut
  is down, or Toggle to press once to start and again to finish. Escape cancels.
- Adds Recording indicator (Settings › Behavior): show the dictation pill at the
  top or bottom of the screen, or hide it.
- Adds Interface language (Settings › Application): English, Chinese, German,
  Japanese, Polish, or Spanish, or follow the system.
- Gives Linux the full app: Modes with app rules on X11, History, microphone
  choice, Paste last dictation, Double-tap only, Release microphone while idle,
  While dictating, the recording indicator on X11 and Wayland, and Voice Action.
- Makes Settings, Modes, Voice Action, and History the same on every platform.
  Windows and Linux settings move into `settings.json` on first launch; the old
  file is kept as a backup.

This macOS release uses build 20300. The public TypeScript SDK remains at
0.3.1.
